# Учет платных подписок (SubTracker)

REST API сервис для трекинга ежемесячных платных подписок (музыка, софт, кино, прочее). Предназначен для личного контроля регулярных расходов.

---

## Стек технологий
* **Python 3.10+**
* **FastAPI**
* **Uvicorn**
* **Pydantic**

---

## Быстрый запуск

### 1. Клонирование и переход в проект
Склонируйте репозиторий на свой компьютер и откройте терминал в папке проекта.

### 2. Создание виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate

```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt

```

### 4. Запуск приложения

```bash
uvicorn main:app --reload

```

После запуска сервер будет доступен по адресу: `http://127.0.0.1:8000`

Для остановки сервера нажмите `Ctrl + C` в терминале.

---

## Документация API

После запуска приложения вы можете использовать встроенные интерактивные интерфейсы для тестирования эндпоинтов:

* **Swagger UI:** `http://127.0.0.1:8000/docs`
* **ReDoc:** `http://127.0.0.1:8000/redoc`

---

## Основные эндпоинты

| Метод | Путь | Назначение |
| --- | --- | --- |
| **GET** | `/health` | Проверка работоспособности сервиса |
| **GET** | `/` | Информация о сервисе |
| **GET** | `/subscriptions` | Получение списка всех подписок |
| **POST** | `/subscriptions` | Добавление новой подписки |
| **DELETE** | `/subscriptions/{id}` | Удаление подписки по идентификатору |

---

## Диагностика и частые проблемы

* **Порт 8000 занят (`Address already in use`):**
Если порт занят предыдущим процессом, завершите его командой:
```bash
sudo fuser -k 8000/tcp

```


Или запустите приложение на другом порту:
```bash
uvicorn main:app --reload --port 8001

```


* **Ошибка импорта или отсутствия модулей (`ModuleNotFoundError`):**
Убедитесь, что виртуальное окружение активировано (`source .venv/bin/activate`) и зависимости установлены (`pip install -r requirements.txt`).
