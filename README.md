# Учет платных подписок (SubTracker)

REST API сервис для трекинга ежемесячных платных подписок (музыка, софт, кино, прочее). Предназначен для личного контроля регулярных расходов.

## Стек технологий

* Python 3.10+
* FastAPI
* Uvicorn
* Pydantic

## Быстрый запуск

1. Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate

```

2. Установите зависимости:

```bash
pip install -r requirements.txt

```

3. Запустите приложение:

```bash
uvicorn main:app --reload

```

После запуска сервер доступен по адресу: `[http://127.0.0.1:8000](http://127.0.0.1:8000)`

Для остановки нажмите `Ctrl + C`.

## Документация API

Интерактивная документация доступна после запуска приложения:

* Swagger UI: `[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)`
* ReDoc: `[http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)`

## Основные эндпоинты

* `GET /health` — проверка работоспособности сервиса.
* Эндпоинты для добавления, просмотра, обновления и удаления подписок.

## Диагностика

Если порт 8000 занят, выполните:

```bash
sudo fuser -k 8000/tcp

```

Или запустите на другом порту:

```bash
uvicorn main:app --reload --port 8001

```
